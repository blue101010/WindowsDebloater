# 471 - Missing Windows 11 controls, prioritized

Scope: Windows 11 **24H2-26H2**; 50 missing enforcement/configuration controls, not 50 controls exclusive to Windows 11. Checked on 2026-11-07. Servicing, edition, application version and hardware prerequisites apply; this is a backlog, **not a script or a universally safe baseline**.

Comparison: [Raphire/Win11Debloat.ps1](https://github.com/Raphire/Win11Debloat/blob/5d88bfe9ef2be5a8a643166a6400eb78a30c46ec/Win11Debloat.ps1), pinned commit `5d88bfe9ef2be5a8a643166a6400eb78a30c46ec` (script version 2026.10.30), including `Config/Features.json`, `Regfiles` and `Scripts/Features/Invoke-Changes.ps1`. BOM-aware registry reads were compared against both repository script folders, including batch files, mixed PowerShell libraries and DSC. Comments and read-only checks do not count as implementation; a different command achieving the same control does count.

`[R]` marks gaps identified in the Raphire comparison; other entries extend the hardening backlog using Microsoft documentation. `DWORD` means REG_DWORD. Values are proposed deployment choices, not all Microsoft defaults. Items 30-32 are alternatives for organizations permitting Recall, not prerequisites for disabling it. **Preference/pilot** entries are upstream candidates, not Microsoft-supported enterprise policies or guarantees across every servicing revision.

## Comparison decisions and limits

- Already implemented: SMB signing (0343), LSA protection (0404), HVCI (0075), Credential Guard (0344-0345), browser DoH, DVR policies, OneDrive controls, many advertising/telemetry/update restrictions. These were not relisted merely because upstream uses another name or registry location.
- Actual gaps: Recall is only checked in 0438; canonical Widgets policy is not written in 0390; Start policy differs from 0468's preferences. Large mixed libraries and deprecated scripts were included, not dismissed by their names.
- Not promoted from upstream: legacy Cortana/WindowsCopilot-button policies, deprecated Chat/Meet Now tweaks, disabling BitLocker auto-encryption, disabling security updates, force-removing Edge, denying Everyone access to Store's database, replacing Game Bar URL handlers, cosmetics, or splitting one Explorer tweak into numerous numbered entries.
- Click to Do and policies whose current CSP applicability remains Insider-only were excluded despite upstream switches. Raw `TurnOffSavingSnapshots` is not treated as an independently documented current policy.
- Read-only PDE status nodes and standalone vulnerable-driver-blocklist deployment were not counted: the former is verification, and existing HVCI already provides blocklist enforcement on the applicable baseline. Smart App Control is a supported UI/provisioning control, not fabricated programmatic activation.
- Documentation establishes minimums and later-version support, not certification of every 26H2 servicing revision. No live hardening/debloating was executed. Preference/pilot entries are explicitly lower-confidence than documented policies; validate candidates on target builds before implementing scripts.
